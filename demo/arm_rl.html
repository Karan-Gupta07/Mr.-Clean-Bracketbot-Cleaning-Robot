Follow the signal

The controller writes the robot observation into afferent neurons, runs four rounds of message passing over the measured wiring, and reads descending neurons. The circuit view groups neurons into cell types and places each type by its typical synaptic hop from the injected set.

Cell types use FlyWire's class annotation where it exists, otherwise super class plus neuropil group. Ranking is by total activation over the whole episode, so the diagram holds still and only the glow follows the clock.

Top cell types this episode

Bars show each type's mean activation at the current frame, relative to the strongest type's episode peak. Links are summed absolute model weights between types, not measured synapse counts.

What the policy sees

The actual 20-value observation used to compute this frame's action. Positions and velocities are scaled ×10; jaw opening ×20; contacts ÷2. The camera images are for display only and are not policy inputs.

Control path

Simulator state → learned input adapter → 4 graph propagation rounds → actor → XYZ increments and jaw opening → inverse kinematics → joint servos.

Every 50 ms the first three outputs move the commanded grip position by up to 4 mm per axis; wrist orientation is fixed downward.

The mapped nodes are engineering interfaces. Those roles do not mean the biological neurons encode robot coordinates.

Does the fly wiring help?

This arm experiment has no matched conventional-network control run, so it cannot answer that. The companion navigation experiment does have one, and the answer there was no:

Navigation policySeeds 2000–2019
Fly graph, imitation only20/20
Fly graph, PPO + rehearsal17/20
MLP, imitation only18/20
MLP, PPO + rehearsal20/20

A plain network of comparable size did the job just as well. What this demo shows is that a controller built on measured fly connectivity can drive a robot arm — not that the connectivity is what makes it work.

Scope

One 48 mm cube randomized by ±8 mm, a fixed 17 cm destination, a fixed base, and Camera perception, base balancing during manipulation, other objects, and hardware behaviour are all unvalidated.

Measured wiring. Learned control.

This controller uses a -neuron subset of the FlyWire FAFB v783 connectome, joined by measured directed neuron pairs. Neuron IDs, transmitter predictions and classifications come from the source tables.

The policy was initialized from demonstrations by behavioral cloning, then trained with PPO plus demonstration rehearsal. It chooses arm motion and gripper opening; IK and servos execute those commands. No scripted phase sequence or timer selects movements at playback.

What the animation means

Node brightness and size show the saved policy's actual activations. The trace follows the same replay clock as the robot. This is finite message passing, not a biological spiking simulation and not a whole fly brain. Edges show connectivity, not measured information flow.

One source annotation point represents each neuron; these dots are not complete neuron morphologies. “Policy interfaces” is a conceptual input/internal/output layout, not anatomical position or synaptic hop count.

Signs and weights

Edge weights are synapse counts aggregated per directed neuron pair, signed by the presynaptic transmitter prediction (GABA and glutamate negative, everything else positive), then normalized by each neuron's total incoming weight. That sign rule is a deliberate engineering simplification, not a biological claim.
