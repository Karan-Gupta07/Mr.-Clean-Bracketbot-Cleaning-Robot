# Project verification

- On Windows, use `.venv\Scripts\python.exe` directly; shell activation is unnecessary.
- Regression suite: `.venv\Scripts\python.exe -m unittest discover -s tests -v`. The bare-gripper grasp test is an expected failure, not proof that the original collision hulls work.
- Navigation unit checks: `.venv\Scripts\python.exe scripts/check_navigation.py`.
- Navigation simulation: `.venv\Scripts\python.exe scripts/navigate.py` runs all nine routes using simulator truth, not ROS localization.
- Regenerate models with `scripts/build_mjcf.py`, then `scripts/build_room.py`. The latter writes both room XML files before checking clearance and reachability.
- Keep `models/bracketbot/chopped_urdf_v2.urdf` and the mesh assets unchanged. Matching-color contact pads are allowed; do not replace the default demo fingers or hinge joints.
- Keep navigation's room solver impedance ratio at 10. Manipulation selects 200 in its own model; setting 200 globally regresses navigation.
- The required stations are red ball/box (`ball`, ACT), colored cubes (`cubes`, Fable), and blue cube/rectangle (`pick`, Flybrain). Crockery is not in the default room.
- Demos, graph data, checkpoints and replay outputs live in ignored `out/`; they are not included in a Git push. Checkpoint/demonstration metadata must match the current environment.
- Arm history experiments use `--history 16` in both `scripts/train_arm.py` and `scripts/run_arm.py`, with a separate `--output` directory. The default remains one observation (control v4); history uses control v5 and records its length. Do not reuse single-frame demonstrations/checkpoints for history training. History resets every episode and contains no teacher phase or future state.
- `scripts/train_arm.py --history 16 --resume <checkpoint> --calibrate-jaw 1.25 --output <new-directory>` scales only the learned jaw-output weights, records the gain, and evaluates the new checkpoint without training or a scripted inference fallback. Its validation report must be regenerated against the new checkpoint hash.
- Optional `--motion-deadband 0.05` suppresses small Cartesian commands without selecting task phases. It uses control v6 and must match between training, calibration, and evaluation; it is not enabled by default. To change only this calibration on an existing checkpoint, use `--calibrate-jaw 1` with the requested deadband and a separate output directory.
- `scripts/orchestrate.py --planner sweep` explicitly validates Fable's skills without API access. Real Fable needs `requirements-agent.txt` and a locally configured `ANTHROPIC_API_KEY`; never put a key in a tracked file.
- Do not equate a supplied recognition label or simulator metadata with camera-based perception, or the separate fixed-base demo with a continuous navigation/manipulation handoff.
- `scripts/run_act.py --describe` describes the ACT scaffold; `--check` and execution intentionally fail before movement until the real backend is supplied. `rlbot.act.prepare_act` is the integration point, registered by both orchestration launchers.
- `scripts/live_demo.py --station cubes --recognized colored_cubes --prompt-api-key` runs the live Fable path using a hidden, process-local console prompt. A real interactive console is required; keys are never report fields. `--report out/<name>.json` records non-secret status/results. API/model access is checked before navigation. `--planner sweep` explicitly selects offline skills instead.
- Live navigation closes its viewer on completion. Fable manipulation opens a separate fixed-base viewer that stays open after completion; close it to finish the result report. Closing during manipulation stops the skill loop. Flybrain still requires its existing perfect checkpoint-bound evaluation gate.
- `scripts/train_arm.py --distill-release --resume <checkpoint> --steps 0` collects successful training-only release corrections and freezes graph/features/value parameters during actor distillation. Neither corrective teacher nor distillation is invoked by policy inference. Seeds 6000-6019 have now been evaluated and are not fresh for future tuning.
